# 想法速记

随手记下想法，一点就存进自己的 GitHub 私有仓库。

- 纯前端，单文件，无服务器、无数据库、无第三方追踪
- 数据通过 GitHub Contents API 直接提交到**你自己的**仓库，每条想法 = 一个 commit
- 断网可记，联网自动补传
- 可添加到手机主屏幕（PWA）

## 使用

1. 用手机浏览器打开本页
2. 点「设置」，填入 GitHub 用户名、数据仓库名、分支、文件夹、访问令牌
3. 令牌建议用 Fine-grained token，只授权数据仓库，权限只需 `Contents: Read and write`
4. 添加到主屏幕

## 隐私

本仓库只有网页代码，不包含任何个人数据。所有想法存在一个独立的**私有**仓库里。
访问令牌只保存在浏览器 localStorage 中，不会发送到除 `api.github.com` 以外的任何地方。
